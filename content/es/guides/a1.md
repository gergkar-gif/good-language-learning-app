# A1 Curriculum

Regenerated 2026-09-16 from `content/es/curriculum/units/a1.json` and the
real lesson/story files — this replaced a hardcoded `build-manifest.py`
`UNIT_TABLES` dict on 2026-09-16 (see `docs/CURRICULUM_ROADMAP.md`'s "How
units get wired in"), and A1's shape changed substantially since this doc
was last rewritten (2026-08-07): 20 sequential lessons became **26 units
of 6 lessons each** (156 lessons total), as six new grammar-topic units
(Reflexive Verbs, Demonstratives, Present Continuous, Doler, Gustar,
Poder/Saber) were inserted and units were retitled/reordered around them.

**The unit table's source of truth is now
`content/es/curriculum/units/a1.json`**, not this file — adding or
reordering a unit means editing that JSON (schema:
`content/es/schemas/units.schema.json`), then running
`python build-manifest.py`. This table is a readable mirror of it, kept
in sync by hand; if the two disagree, the JSON wins.

Title is the topic, never the story — the story has its own name and it
lives in the story file. "Ordering at a Café", not "Café con Meg".

## Overview

Each unit is 5 teaching lessons + 1 consolidation lesson. "Goal" and
"Grammar" below are the unit's *first* lesson's own fields (a unit
typically builds up to 3-4 grammar points across its 5 lessons — see
`a1-grammar.md` for the full per-lesson breakdown). A "—" in Story means
no lesson in that unit currently links a reading; six units' stories
exist as files but aren't wired into a lesson yet (see the note below the
table).

**The six "—" units already have a written story** — `content/es/stories/original/a1/a1-reflexive.json`,
`a1-demonstrative.json`, `a1-continuous.json`, `a1-doler.json`,
`a1-gustar.json`, `a1-abilities.json` all exist with real titles and
summaries (see `docs/CURRICULUM_ROADMAP.md`'s Phase 1 table) — they're
just not referenced from any lesson's `story` section yet, so they don't
currently appear in that unit's lesson flow (though they're readable
directly in the Library). Wiring them in is a content-authoring task, not
a documentation fix; noted here so it isn't mistaken for "no story was
ever written."

Also note some units' `grammar` field (e.g. `pronombres-reflexivos`,
`este-esta`, `me-duele`) is a terse internal slug rather than a clean
label like "Greetings" — that's the actual data in those lesson files,
not a transcription choice in this table.
