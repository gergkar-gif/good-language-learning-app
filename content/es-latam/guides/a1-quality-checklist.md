# A1 Lesson Quality Checklist

Every lesson must satisfy all of the following before it is considered complete.

---

## Curriculum

- [ ] One communicative goal.
- [ ] One primary grammar point.
- [ ] Follows the A1 grammar progression.
- [ ] Follows the A1 vocabulary progression.

---

## Vocabulary

- [ ] Uses only words from the Core Lexicon.
- [ ] Introduces the correct number of new words.
- [ ] Key new vocabulary appears in the unit's story.
- [ ] Every new word appears in at least one exercise.
- [ ] Every new word is added to SRS.

---

## Story

- [ ] Continues the main narrative.
- [ ] Uses only grammar already introduced.
- [ ] Mostly reuses previously learned vocabulary.
- [ ] Advances the plot.

---

## Grammar

- [ ] Explanation is concise.
- [ ] Examples are natural.
- [ ] Includes a Lingolia reference.

---

## Exercises

- [ ] Vocabulary exercises completed.
- [ ] Grammar exercises completed.
- [ ] Reading exercises completed.
- [ ] Dialogue exercises completed.
- [ ] Writing exercise completed.

---

## Reading

- [ ] Original story only (every A1 lesson with a story).

---

## Completion

- [ ] Can-do checklist completed.
- [ ] Estimated lesson time is appropriate.
- [ ] Lesson reviewed for consistency with previous lessons.
