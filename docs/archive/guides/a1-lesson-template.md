# A1 Lesson Template

A blank skeleton for a new teaching lesson. See `a1-content-spec.md` for
the rules each section must satisfy and `scripts/audit-lesson.py` for what's
actually enforced. For a consolidation lesson, use the different shape in
`a1-content-spec.md` §5 instead (no grammar/vocabulary/SRS, one "Review"
block) — this template is for a teaching lesson only.
