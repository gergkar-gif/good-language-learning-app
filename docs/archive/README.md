# Archive

Docs moved out of the repo root because the work they describe is done, or
the curriculum shape they describe is no longer what's actually built.
Kept for history, not for guidance — nothing in this folder should be
treated as a current spec.

- `HUNGARIAN_HANDOVER.md`, `HUNGARIAN_WORKSHOP_IMPLEMENTATION_HANDOVER.md`,
  `HUNGARIAN_READER_IMPLEMENTATION_BRIEF.md` — "start here" briefs for the
  Hungarian Verb Driller, Workshop drillers, and Reader/Lexicon. All three
  are built and live; see memory `hungarian-workshop-drillers` and
  `hungarian-reader-lexicon-built` for what actually shipped.
- `MULTI_LANGUAGE_READINESS_AUDIT.md` — a 2026-08-18 snapshot of
  Spanish-only assumptions across the app. Many more multi-language
  passes have happened since; treat this as historical, not a live gap
  list.
- `curriculum-map.md` — self-declared superseded even at the time it was
  written. The real curriculum lives in `content/es/curriculum/curriculum.json`
  (and `content/hu/curriculum/curriculum.json`), generated by `build-manifest.py`.
- `HUNGARIAN_A1_CURRICULUM.md` — describes a 40-unit / 215-lesson shape
  that was never what got built. The actual Hungarian A1 is 30 units,
  150 lessons — see `content/hu/curriculum/curriculum.json` and memory
  `hungarian-a1-unit1-25step-model`.
- `PARLOUR_DECKS_SPEC.md`, `PARLOUR_LIBRARY_SPEC.md`,
  `PARLOUR_LISTENING_SPEC.md`, `PARLOUR_VOCABULARY_DRILLER_SPEC.md` —
  implementation specs for Decks, Library, the Listening Driller, and the
  Vocabulary Driller. All four features are built; see memory
  `parlour-decks-my-decks-feature`, `parlour-library-my-texts-feature`,
  `parlour-listening-driller`, `parlour-vocabulary-driller-redesign` for
  what actually shipped (which drifted from these specs in places during
  implementation — the memory entries are the more accurate record).
