# Project Structure

Spanish Mastery uses a strict separation of concerns across seven top-level directories.

## Rule: One Responsibility Per Folder

| Folder | Responsibility | Edited By |
|--------|---------------|-----------|
| `engine/` | Application logic | Developers |
| `content/` | Educational content | Curriculum authors |
| `imports/` | External resources | Import scripts only |
| `generated/` | Machine-generated files | Build scripts only |
| `assets/` | Static media | Designers / authors |
| `scripts/` | Automation | Developers |
| `docs/` | Documentation | Everyone |

---

## `engine/`

**What:** All application logic. How to teach, render, store, and review.

**What NOT:** No Spanish words, no grammar explanations, no stories.

| File | Purpose |
|------|---------|
| `init.js` | Bootstrap: tab switching, CSS injection, event wiring, app startup |
| `xp.js` | XP system: scoring, streaks, daily caps, notifications |
| `srs.js` | Spaced repetition: deck management, review scheduling, ratings |
| `reader.js` | Reader: word popup, familiarity coloring, wordDB integration |
| `verbs.js` | Verb drills: tense selection, conjugation checking, verb loading |
| `lessons.js` | Lesson engine: step rendering, quiz checking, lesson flow |
| `loader.js` | *(placeholder)* Generic JSON content loader |
| `storage.js` | *(placeholder)* LocalStorage abstraction |
| `ui.js` | *(placeholder)* Shared UI helpers and animations |

**Load order** (in `index.html`, bottom-up dependency chain):

```
imports/verbs/verb-list.js
engine/xp.js
engine/srs.js
engine/reader.js
engine/verbs.js
engine/lessons.js
engine/init.js
```

---

## `content/`

**What:** Everything authored specifically for Spanish Mastery. The project's intellectual property.

**What NOT:** No engine logic, no external dictionaries, no generated files.

| Subfolder | Contains |
|-----------|----------|
| `curriculum/` | Curriculum files defining lesson order and progression |
| `lessons/` | Individual lesson JSON files (references only, no embedded content) |
| `stories/` | Graded reader stories (prose, character dialogue) |
| `grammar/` | Grammar explanations by topic |
| `exercises/` | Quiz questions, drills, production prompts |
| `characters/` | Character biographies and profiles |
| `culture/` | Cultural notes and context |
| `writing/` | Writing prompts and templates |
| `listening/` | Listening comprehension materials |

**Content references content by stable ID.** Example lesson:

```json
{
  "id": "lesson.a1.01",
  "title": "Greetings & Introductions",
  "level": "A1",
  "grammar": ["grammar.ser", "grammar.estar"],
  "vocabulary": ["hola", "casa", "ser"],
  "story": "story.a1.01",
  "exercises": ["exercise.a1.01.001"],
  "characters": ["character.ana"]
}
```

## `imports/`

**What:** External resources. Never edited manually. Updated via import scripts.

| Subfolder | Source | Contains |
|-----------|--------|----------|
| `dictionary/` | Kaikki (Wiktionary) or similar | Word definitions, pronunciations, examples |
| `verbs/` | miko3k/verbos GitHub repo | Verb conjugation JSON files |
| `frequency/` | Open-source frequency lists | Word frequency rankings |
| `pronunciation/` | External APIs | IPA, audio references |
| `audio/` | External sources | Pronunciation audio files |
| `images/` | External sources | Stock images, reference photos |

**Current files:**
- `imports/verbs/verb-list.js` — generated list of all available verbs
- `imports/verbs/*.json` — individual verb conjugation files (600+), imported from miko3k/verbos

---

## `generated/`

**What:** Machine-generated files. Build artifacts. Never edited manually.

| Subfolder | Generated By | Contains |
|-----------|--------------|----------|
| `indexes/` | `build.py` | Lookup indexes for fast content loading |
| `search/` | `build.py` | Search indexes for words and content |
| `statistics/` | `build.py` | Lesson stats, word counts, coverage reports |
| `cache/` | Build scripts | Cached processed data |

---

## `assets/`

**What:** Static media created for the project.

| Subfolder | Contains |
|-----------|----------|
| `images/` | UI images, illustrations |
| `audio/` | Custom audio recordings |
| `icons/` | App icons, UI icons |
| `fonts/` | Custom typefaces |
| `illustrations/` | Story illustrations, character art |

**Difference from `imports/images/`:** `assets/` contains original work. `imports/images/` contains external/stock media.

---

## `scripts/`

**What:** Python automation scripts.

| File | Purpose |
|------|---------|
| `import_dictionary.py` | Fetch and process external dictionary data (e.g. Kaikki/Wiktionary) |
| `import_verbs.py` | Fetch verb conjugation JSONs from miko3k/verbos GitHub repo |
| `build_verb_list.py` | Scan `imports/verbs/*.json` and regenerate `verb-list.js` |
| `build.py` | Generate indexes, validate JSON, produce statistics |
| `validate.py` | Detect broken references, duplicate IDs, missing assets |
| `generate_indexes.py` | Build engine lookup indexes |

---

## `docs/`

**What:** Project documentation.

| Subfolder | Contains |
|-----------|----------|
| `architecture/` | System design, data flow, decisions |
| `schemas/` | JSON schemas for all content types |
| `editorial/` | Style guides for content authors |
| `roadmap/` | Sprint plans, milestones |
| `ideas/` | Feature ideas, research notes |

---

## What Goes Where: Decision Flowchart

```
Is it application logic?
  → YES → engine/

Is it educational content you wrote?
  → YES → content/

Is it from an external source?
  → YES → imports/

Was it created by a script?
  → YES → generated/

Is it static media you created?
  → YES → assets/

Is it documentation?
  → YES → docs/

Is it a build/import script?
  → YES → scripts/
```
