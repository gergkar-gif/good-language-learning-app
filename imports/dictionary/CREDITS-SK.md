# Slovak Dictionary & Linguistic Resource Credits

The Slovak course linguistic data in Parlour is built using open-source resources:

1. **Kaikki.org / Wiktionary**:
   - Dictionary lemmas, English glosses, grammatical gender, verbal aspect, and morphological inflection tables.
   - Author: Tatu Ylonen & Wiktionary contributors.
   - Website: https://kaikki.org/dictionary/Slovak/
   - License: Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0) and GNU Free Documentation License (GFDL).

2. **HermitDave FrequencyWords**:
   - Lemma frequency rankings derived from OpenSubtitles 2018.
   - Author: HermitDave
   - Repository: https://github.com/hermitdave/FrequencyWords
   - License: Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0).

3. **FreeDict (slk-eng)**:
   - Slovak-English bilingual translation database.
   - Author: FreeDict contributors
   - Repository: https://github.com/freedict/fd-dictionaries
   - License: GNU General Public License v3.0 or later (GPL-3.0-or-later).

4. **MichMech Lemmatization Lists**:
   - High-coverage Slovak lemma-token pairs compiled from open Hunspell / OpenOffice resources.
   - Author: Michal Měchura
   - Repository: https://github.com/michmech/lemmatization-lists
   - License: Open Database License (ODbL).
