Genre: interview transcript
Lesson plan:
- 01 NEW `marcadores-conversacionales`, screen `c1-18-01-a-gr`: markers that organise talk and show attitude, pan-Hispanic: *pues* (starting an answer, drawing a consequence), *bueno* (accepting, changing topic), *mira / mire* and *oye / oiga* (calling attention: *tú* vs *usted*), *o sea* (you know it from B2 Unit 29 as reformulation: recap), *¿no?* and *¿verdad?* (seeking agreement), *vamos* (summing up: *vamos, que no viene*). Regional markers for recognition only, never as a right answer in a pan-Hispanic item: Spain *vale*, *venga*, *hombre*; Mexico *órale*, *¿mande?*; River Plate *che*, *dale*. Items pin the function in the prompt ("Which marker asks for agreement?") so one marker fits. At least 6 items tagged with it.
- 02 hesitating and gaining time: vocabulary-led (*este…*, *a ver*, *es que…*), tagged `c1-conversation-markers-vocab`; recap `refutacion-no-es-que-sino` (B2) for *No es que…, es que…* only if it fits.
- 03 agreeing and disagreeing in conversation: recap `subjunctive-doubt` (B1): *No creo que tengas razón*, *Puede que sí*.
- 04 telling what someone said in conversation: recap `discurso-indirecto-deicticos` (B2).
- 05 the rhythm of an interview: recap `stance-adverbs` (B2) in speech (*la verdad, francamente*); plus the text and the Reading group.
Domain words: conversation (*la charla, el entrevistador, el entrevistado, la pregunta* only if not listed, *interrumpir* only if not listed, *la pausa, retomar*); check each against the sheet.
Text: an interview transcript in an invented local radio programme: an interviewer and an unnamed guest (*la invitada*, a baker who opened a shop) talking; it uses the markers naturally, pan-Hispanic ones only. No real programme or person.
