Lesson plan:
- 01 NEW `verbos-doble-modo`, screen `c1-12-01-a-gr`: verbs whose meaning changes with the mood of the clause after them. *decir que* + indicative = report (*Dice que llueve*), + subjunctive = tell someone to (*Dice que vengas*); *sentir que* + indicative = perceive (*Siento que algo cambia*), + subjunctive = regret (*Siento que no puedas venir*); *comprender/entender que* + indicative = realise a fact, + subjunctive = find it understandable (*Entiendo que estés molesto*); *temer que* + indicative = suspect (*Me temo que no hay entradas*), + subjunctive = fear (*Temo que llueva*); *suponer que* + indicative = assume, + subjunctive = imply (*Eso supone que tengamos que pagar*).
